# せどり比較

**iPhone** と **ポケカBOX** を中心に、仕入れ値と各販路（買取店・メルカリ・ヤフオク・ラクマ）の相場から
**手数料・送料を引いた手取り利益**をランキング表示するサイトです。HTML / CSS / JavaScript のみ（ビルド不要）。

## できること

- **カテゴリタブ**：iPhone／ポケカBOX／すべて を切り替え
- **表彰台**：上位3つを🥇🥈🥉のカードで表示
- **利益ランキング**：商品ごとに一番儲かる販路・利益・利益率を自動計算
- **並び替え・絞り込み**：利益順／利益率順／売れ行き順、カテゴリ、黒字のみ、検索
- **内訳表示**：行をクリックすると販路ごとの「販売価格−手数料−送料−仕入れ値」を表示
- **★ウォッチ**：気になる商品に印をつけて絞り込み（ブラウザに保存）
- **利益計算**：仕入れ値・販売価格・送料を入れると利益と損益分岐価格を計算
- **手数料設定**：販路ごとの手数料率を変更可能（ブラウザに保存）
- ライト／ダークモード、スマホ表示（カード形式）対応

## 商品データの編集

`assets/data.js` の `PRODUCTS` を書き換えます。

```js
{ id: 1, cat: "iPhone", name: "商品名", note: "未開封・SIMフリー", store: "仕入れ先",
  buy: 10000,   // 仕入れ値
  ship: 750,    // 送料
  sold: 100,    // 月間の売れた数
  prices: { kaitori: 14000, mercari: 15000, yahoo: 14500, rakuma: null } }  // null = 取り扱いなし
```

`cat` は `"iPhone"` か `"ポケカBOX"`。相場を更新したら `UPDATED` の日付も変えてください。
買取店は手数料0%・送料なしで計算します。

※ 最初に入っている相場はサンプルです。手数料率も目安なので、各サービスの最新の料金を確認して設定してください。

## 公開（GitHub Pages）

Settings → Pages → 「Deploy from a branch」でブランチと `/ (root)` を選んで保存。

## 注意

チケット（チケット不正転売禁止法）、医薬品、酒類など、法律で転売や販売に許可が必要な商品は扱わないでください。
