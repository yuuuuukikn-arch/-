# 買取相場ナビ

**iPhone 18シリーズ** と **ポケカBOX** の買取価格から、「定価で買って買取店に売ったときの利益」をランキング表示し、
毎日の買取価格を記録して**価格推移グラフ**を表示するサイトです。HTML / CSS / JavaScript のみ（ビルド不要）。

## できること

- **速報**：ページ上部に1件ずつ表示（複数あれば5秒ごとに切り替え）。表示期間を過ぎると自動で消える。押すと速報ページ（`news.html`）の記事へ
- **カテゴリ切り替え**：画面上部の「iPhone｜ポケカ」
- **表彰台**：上位3つを 🥇🥈🥉 で表示
- **比べ方**：iPhone は「買取率 = 買取価格 ÷ 定価」、ポケカは「利益 = 買取価格 − 定価」で並べ替え
- **店舗別ランキング**：各商品の中に店を高い順（1位・2位・3位）に並べ、価格と買取率（ポケカは利益）を表示。押すとその店のサイトへ
- **店舗比較**：詳細を開くと、店舗ごとの買取価格（iPhone は色別）と利益、備考・営業時間
- **ランキング表**：定価、買取価格（未開封）、前回比、推移（ミニグラフ）、利益、利益率、強化中バッジ、色による減額メモ
- **価格推移グラフ**：行をクリックすると、各店の中の最高値の推移と定価ライン（ホバーで最高値の店と買取率）（7日／30日／全期間）
- 黒字のみ表示、検索
- **スマホ優先のデザイン**：上位3つは横スワイプ、ランキングはスマホ専用カード、店舗は1行まるごと押せるボタン。ホーム画面に追加できるアイコン付き
- ライト／ダークモード

## 毎日の価格の取り込み

買取店のページをコピーしたテキストを保存して、取り込みスクリプトを実行します。

```sh
# 1. コピペしたテキストを保存
#    data/raw/2026-10-08_買取一丁目.txt
# 2. 取り込み（assets/history.js に追記されます。同じ日付・同じ店なら上書き）
python3 tools/import_kaitori.py "data/raw/2026-10-08_買取一丁目.txt" --date 2026-10-08 --shop 買取一丁目
# ポケカBOXのリストの場合
python3 tools/import_kaitori.py "data/raw/2026-10-08_買取一丁目_ポケカ.txt" --date 2026-10-08 --shop 買取一丁目 --cat ポケカBOX
# 2ページ目以降は --append で前のページに追加
python3 tools/import_kaitori.py "data/raw/2026-10-08_森森買取_p2.txt" --date 2026-10-08 --shop 森森買取 --append
```

次の書き方を自動で見分けて読み取ります。

- **買取一丁目形式**：「商品名 → 新品 → （JAN・備考）→ 価格の見出し → ¥価格」。
  iPhone 18 の「ブラック,グレイシャー -20000,シルバー -25000」は、数字の前に並んだ色をその金額だけ減額、書かれていない色（バーガンディ）を満額として色別価格に変換します。
- **買取ルデヤ形式**：「新品 → 機種 容量 色 型番 未開封 SIMフリー → JAN → 買取価格 → 000,000円」。色ごとの行を機種ごとにまとめます。
- **買取商店形式**：「[機種 容量 色 型番 SIMフリー](URL) → JAN → 新品¥000,000 → 中古¥…」。ページをそのままコピーした形で読めます。「新品」の価格を未開封として使います。
- **森森買取形式**：「Apple iPhone18 Pro 256GB 色 SIMフリー → JAN → 通常・預かり・即フリの3価格」。「通常買取価格」を使います（見出しなしでコピーした形も可）。
価格の見出しは「未開封」「新品未開封」「シュリンク有」を未開封の価格として使い、「シュリンクなし未開封」「開封済未使用」は記録だけします（シュリンクなしは一覧に小さく表示）。
サイトでは未開封の価格を使います（開封済未使用の価格は記録だけして表示しません）。
ポケカなど店ごとに商品名の書き方が違うものは、JAN コードが同じ登録済み商品の名前にそろえます。JAN が合わない商品（ほかのジャンルなど）は取り込まずに一覧で表示します。
iPhone は 18 シリーズだけ表示します（`assets/data.js` の `SHOW_ONLY` で変更可。取り込んだデータはすべて記録されます）。
各店の価格は、その店の最新の取り込みを3日間有効として比べます（店ごとに取り込む日がずれても比較から消えないように。古い店には「10/07時点」と表示）。

## 予約・抽選・新発売・注目ページの作り方

`assets/pages.js` の `PAGES` に1件ずつ書き、`node tools/make_pages.js` を実行すると、次が作られます。

- `p/<id>.html`：商品ページ（`status: "draft"` は下書き。リンクは出ず、検索に出ない）
- `yoyaku.html`：予約・抽選・新発売の一覧（公開分のみ）
- TOP の「注目」欄：掲載中（`until` 前）の公開分を新しい順に6件まで

アフィリエイトは `assets/pages.js` の `PAGE_CONFIG`（Amazon の ID・楽天の ID）を入れると、各商品ページに付きます。空のままなら付きません。抽選品など通販リンクを付けない商品は `buyable: false` にします。

## 記事（価格の比較・推移グラフ）

`assets/pages.js` の `ARTICLES` に `kind: "article"` と `chart: { cat, name }` を書いて `node tools/make_pages.js` を実行すると、最新の価格の表と推移のグラフ付きの記事ができます。記事はランキングの下に並びます。公開しない店は `tools/make_pages.js` の `ARTICLE_EXCLUDE` に入れます（今は買取商店）。

## 発売カレンダー

`assets/pages.js` の `RELEASES` に予約開始日時と発売日を書いて `node tools/make_pages.js` を実行すると、次が作られます。

- `calendar.html`：発売カレンダーのページ（予約開始・発売日、状態、「予約した」の記録、公式へのリンク）
- `ics/<id>.ics`：その商品の予定ファイル（「カレンダーに追加」で、スマホのカレンダーに入る。予約開始の1時間前に通知）
- `calendar.ics`：全部の予定（スマホのカレンダーで購読すると、増えた予定が自動で入る）

「予約した」の記録は、この端末のブラウザにだけ保存されます。日程は必ず公式で確認してから公開してください。

## 速報の追加

`assets/data.js` の `NEWS` に追加します。ランキングページの上部には `date` から `until` の日まで表示されます（`until` を省略すると `date` から `NEWS_DAYS` 日間）。
速報ページ（`news.html`）には期間が過ぎたものも「終了」として残ります。

```js
{ id: "pgu-nu", date: "2026-10-08", until: "2026-10-15", tag: "ガンプラ",
  title: "○○がプレ値に", body: "本文", retail: 66000, market: 92000,
  url: "https://...", source: "出典名" },
```

## 店舗の追加

`assets/data.js` の `SHOPS` に店名・URL・営業時間を追加します（取り込み時の `--shop` と同じ名前）。並び順がグラフの線の色の順になります。

## 定価の編集

`assets/data.js` の `CATALOG` に商品名と定価を登録します（取り込んだ商品名と完全に一致させる）。
定価が未登録の商品は「未登録」と表示され、利益は計算されません。
`estimated: true` は推定の定価なので、正しい金額がわかったら書き換えてください。

## ファイル構成

- `index.html` / `assets/style.css` / `assets/script.js` — サイト本体
- `assets/chart.js` — 価格推移グラフ（外部ライブラリなし）
- `news.html` / `assets/news.js` — 速報ページ
- `assets/data.js` — 定価の一覧、ポケカのサンプルデータ
- `assets/history.js` — 買取価格の履歴（自動生成）
- `tools/import_kaitori.py` — 取り込みスクリプト
- `data/raw/` — 取り込んだ元テキストの保管
